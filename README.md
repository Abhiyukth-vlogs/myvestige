# myvestige

1:1 exact reproduction of [global.myvestige.com](https://global.myvestige.com/) built with Vite, HTML5, modern CSS, and interactive digital features.

## 🌟 Key Features
- **Header & Navigation**: 1:1 authentic layout with Royal Blue styling (`#1f579c`), Country selector with flags, Language popup modal, and Distributor Login.
- **Announcement Modal**: On-load popup for *10 Shades of Life - MOM All Seasons Nail Lacquer*.
- **Banner Slider**: Left vertical indicator dots and auto-rotating authentic AWS S3 banners.
- **7-Button Action Ribbon**: High-visibility links for *Vestige New Website, Grievance Redressal, Mobile App, Schedule, Online Shopping, Bank PAN, Courier Partner*.
- **4 Feature Cards**: *Monthly Schemes, What's New, Vestige Leadership Series, Car Achievers*.
- **18 Authentic Brands Grid**: Complete brand identity matrix (Assure, Ayusante, Prime, Zeta, Mistral of Milan, Skin Formula 9, etc.).
- **Reach Out Section**: Corporate office details, 11-category grievance form with captcha validation, and direct nodal officer contacts.
- **Victor AI Assistant**: Interactive 24/7 digital assistant chat emulation with quick-help prompts.
- **Anti-Gravity UI**: Micro-interactions, zero-G particle physics canvas, and 3D parallax card tilt physics.

## 🚀 Getting Started
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) or [http://localhost:3001](http://localhost:3001) in your browser.
